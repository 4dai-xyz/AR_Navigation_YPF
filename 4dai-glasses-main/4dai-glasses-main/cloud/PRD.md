# 云端子项目 PRD

更新时间：2026-04-28

## 1. 文档目标

本文档定义 AI 智能眼镜项目中云端子项目的职责、范围、核心接口和验收口径。本文档聚焦首版 Demo 的服务端能力，不展开客户端交互设计和外业建图流程。

## 2. 子项目定位

云端子项目是首版室内导航链路的计算中心，负责：

1. 接收 App 上传的图像和定位请求
2. 基于预建图与定位资产执行视觉重定位
3. 根据当前位置与目标点计算室内路径
4. 向 App 返回可消费的定位与导航结果
5. 为联调、验证和演示提供稳定可观测的接口服务

## 3. 服务对象

- App 子项目
- 建图标注子项目产生的场馆包
- 算法评估脚本与联调测试人员

## 4. 范围

### 纳入范围

- 场馆地图包读取
- 视觉定位接口
- 室内路径规划接口
- 场馆元数据接口
- 健康检查接口
- 业务错误码
- 超时控制
- 置信度分级
- 基础日志

### 不纳入范围

- 订单系统接入
- 用户账号体系
- 多租户管理后台
- 自动建图平台
- 在线模型训练平台

## 5. 核心接口

首版必须提供以下接口：

- `GET /api/v1/health`
- `GET /api/v1/venues/{venue_id}/meta`
- `POST /api/v1/localization/visual-locate`
- `POST /api/v1/navigation/indoor-route`

接口字段约束以 `contracts/openapi/indoor-navigation-api-v1.yaml` 为准。

## 6. 功能要求

### 6.1 场馆包加载

服务必须能够加载单个可用场馆包，并读取：

- 场馆信息
- 楼层信息
- POI
- 入口点
- 跨层连接点
- 路网
- 定位 keyframe 与特征资产

### 6.2 视觉定位

服务必须支持接收图片和定位上下文，返回：

- `status`
- `floor_id`
- `position`
- `confidence`
- `failure_stage`
- `suggested_action`
- `latency_ms`

### 6.3 路径规划

服务必须根据起点和目标 POI 返回：

- `path_nodes`
- `next_turn`
- `distance_to_next_turn`
- `distance_to_target`
- `cross_floor_required`

### 6.4 错误与超时

服务必须对外暴露明确的业务错误语义，包括但不限于：

- 参数错误
- 场馆不存在
- 楼层不存在
- 目标 POI 不存在
- 定位超时
- 路径规划失败
- 路径规划超时
- 内部错误

### 6.5 日志与置信度

服务必须记录联调用最低必需日志，包括：

- `request_id`
- `venue_id`
- `capture_mode`
- `status`
- `confidence`
- `failure_stage`
- `latency_ms`

服务必须具备统一置信度策略，以支持 App 识别 `ok`、`low_confidence` 和 `not_found`。

## 7. 非功能要求

- 首版优先稳定性和可解释性。
- 室内定位请求超时必须可配置。
- 路径规划请求超时必须可配置。
- 对同一场馆包的解析逻辑必须一致供定位与路径规划共用。

## 8. 外部依赖

- 场馆地图包规范
- App 上传的图像与上下文
- 视觉定位 baseline
- 离线评估脚本

## 9. 验收口径

满足以下条件可认为云端子项目达到首版 Demo 可用状态：

1. OpenAPI 与实际接口字段一致。
2. 健康检查、场馆元数据、定位、路径规划四个接口均可调用。
3. 视觉定位可返回 `ok`、`low_confidence`、`not_found` 三类状态。
4. 路径规划可输出跨层路径与转向提示。
5. 超时场景可返回业务超时码与 `504`。
6. 基础单元测试和 smoke test 可运行。
