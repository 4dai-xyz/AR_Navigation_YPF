# AI 智能眼镜室内外一体化导航 Demo PRD V0.2

更新时间：2026-05-06

## 1. 文档定位

本文档用于定义当前仓库所对应的产品边界、默认演示方式、验收口径和长期目标区分。

本文档有两个重点：

- 说明当前仓库已经能演示什么
- 明确哪些能力只是保留在代码和文档里，还没有成为当前默认产品流程

## 2. 产品愿景

面向外卖员提供“室外骑行 + 室内步行”的一体化导航辅助能力。

项目愿景：

`让世界没有难送的外卖`

## 3. 当前版本定义

当前版本不是“真实室内自动定位已经打通的成品”，而是一个可运行、可演示、可继续联调扩展的 Demo 壳子。

当前仓库口径：

- 室外：真实高德导航
- 室内：高德室内底图 + `manual_demo`
- 云端：重定位和路径规划代码保留，但暂不作为当前室内默认主流程

## 4. 目标用户与场景

### 4.1 目标用户

- 外卖员

### 4.2 典型场景

1. 外卖员在 App 中选择目标店铺。
2. App 使用真实高德完成室外骑行或步行导航。
3. 到达最接近目标店铺的入场口附近后，演示人员手动点击 `Enter Venue`。
4. App 切到高德室内底图。
5. 室内阶段通过方向键和楼层键推进 `manual_demo`。
6. App 在顶部状态卡和室内地图上展示方向提示、跨层提示和到达状态。

## 5. 当前 Demo 主流程

### 5.1 当前默认主流程

- 目标输入：手动选择
- 室外导航：真实高德
- 入场切换：手动 `Enter Venue`
- 室内底图：高德室内地图
- 室内推进方式：`manual_demo`
- 楼层切换：手动楼层按钮
- 方向提示：手动方向按钮驱动

### 5.2 当前保留但非默认的能力

- `Capture & Locate`
- `Request Route`
- 云端视觉重定位
- 云端室内路径规划
- 真实场馆高精地图包加载后的自动化联调

这些能力仍然保留在仓库中，用于后续恢复真实室内自动定位链路，但当前不作为主界面第一层操作流。

## 6. 当前范围

### 6.1 当前包含

- Android 手机端主交互壳子
- 室外真实高德导航
- 室内高德底图显示
- 室内 `manual_demo`
- Debug 联调面板
- 云端服务骨架、接口和契约
- 场馆包样例、校验、发布和离线评估脚手架

### 6.2 当前不包含

- 眼镜端独立运行
- 眼镜端显示
- 室外到室内自动切换
- 当前默认启用的室内云端重定位
- 当前默认启用的真实室内自动路径规划
- 多场馆在线生产部署平台

## 7. 当前验收口径

当前仓库对应的验收口径是“演示链路可运行、文档与代码一致”，不是“真实场馆精度指标已经达成”。

当前应以以下结果作为主验收口径：

- Android App 可运行真实高德室外导航
- 室内 `Enter Venue` 后可切到高德室内底图
- `manual_demo` 可完成室内演示
- Debug 面板保留云端联调入口
- 样例场馆包、Cloud 接口和文档契约保持一致

## 8. 长期目标指标

以下指标仍保留为项目长期目标，但不作为当前 `manual_demo` 默认链路的验收条件：

- 在某商场 3 层内，从 A 店到 B 店，80% 时间定位误差小于 3 米
- 转弯提示成功率大于 90%
- 室内单次定位返回时延控制在 2-3 秒级

这些指标适用于后续恢复真实场馆、真实图片、云端重定位和自动室内路径引导后的版本。

## 9. 主要依赖与风险事实

### 9.1 已知依赖

- 高德室外导航能力
- 高德室内底图覆盖情况
- 场馆包规范和样例数据
- 云端接口契约
- 眼镜到手机的图像链路能力验证

### 9.2 当前主要风险事实

- 首个真实场馆包尚未入库
- 真实室内云端定位链路尚未恢复为主流程
- 高德室内底图是否覆盖目标商场不由 App 控制
- 眼镜真实采图链路仍待硬件联调
