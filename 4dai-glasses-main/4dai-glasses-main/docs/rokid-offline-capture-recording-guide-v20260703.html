VisionRoute Rokid 离线采集录制操作说明

用于手机端统一控制 Rokid 眼镜端本地录像与 IMU 采集，录制完成后下载结构化 session 到手机/PC 做后处理。

手机端 APK：VisionRoute Android Debug 眼镜端：VisionRoute RokidBridge 1.6 / versionCode 7 默认采集：1280×720，60 FPS，IMU 目标 200Hz 时间基准：Android elapsed realtime / Camera PTS

1. 采集链路说明

离线采集模式不依赖实时图传和实时定位。手机只负责发起控制、查看状态和下载结果；眼镜端本地完成录像、IMU 采样和文件封装。

角色职责
Android 手机 App发现眼镜 IP、检查采集状态、开始/停止采集、下载最新 session。
RokidBridge 眼镜端 App运行 HTTP 服务，执行 Camera2 + MediaCodec 录像，记录 IMU JSONL 和逐帧 CSV。
PC可选，用于接收从手机导出的 session ZIP 并做后处理。

2. 准备工作

  • 手机和 Rokid 眼镜连接同一个 Wi-Fi，或眼镜连接手机热点。
  • 手机已安装本次 release 中的 app-debug.apk。
  • 眼镜端已安装或可通过手机 App 更新 visionroute_rokid_bridge.apk。
  • 眼镜端相机权限已允许；首次打开 RokidBridge 时如弹权限框，需要允许。
  • 建议眼镜电量充足，长时间采集前先确认温度不要过高。
如果只是做离线采集，不需要启动 PC 后台，也不需要实时 HTTP 图传持续运行。

3. 安装与更新

3.1 安装手机 App

  1. 下载 release 附件中的 app-debug.apk。
  2. 安装到 Android 手机。若系统提示“未知来源”，允许当前安装器安装。
  3. 安装完成后打开 VisionRoute App。

3.2 安装或更新眼镜端 RokidBridge

  1. 在手机 App 中进入隐藏调试入口，打开 Rokid 调试页。
  2. 点击 授权，按 Rokid 授权流程完成授权。
  3. 点击 连接 App，等待 CUSTOMAPP 会话建立。
  4. 点击 安装/更新眼镜端 App。App 会先比对眼镜端版本和本地内置版本。
  5. 若版本一致，页面显示“无需更新”；若版本不一致，会上传并安装新版 RokidBridge。
  6. 点击 打开眼镜端，或在眼镜端手动打开 VisionRoute RokidBridge。
本次 release 内置眼镜端版本应显示为 1.6 / versionCode 7。

4. 开始一次离线采集

  1. 确认眼镜端 RokidBridge 已打开，眼镜和手机处于同一网络。
  2. 在手机 App 的 Rokid 调试页找到 离线采集（录像 + IMU） 卡片。
  3. 点击 采集状态。手机会优先使用已保存地址；失败时会自动扫描局域网查找眼镜 HTTP 服务。
  4. 状态正常时应能看到眼镜端版本、采集状态、最近 session 信息等。
  5. 点击 开始采集。
  6. 确认状态变为 recording，并观察以下数据持续增长：encoded_frame_count、camera_capture_result_count、imu_sample_count、video_bytes。
  7. 正式录制时保持眼镜佩戴姿态稳定，按需要完成场景采集。
字段正常含义
actual_width / actual_height实际录像分辨率，当前目标为 1280×720。
fps_rangeCamera2 选到的 FPS 范围，理想值为 [60, 60]。
actual_video_fps实际编码帧率，短时间内允许波动，稳定后应接近目标 FPS。
actual_imu_hz实际 IMU 样本频率；当前采集会同时注册多个传感器，因此总样本 Hz 可能高于 200。
battery_temperature_c电池温度，长时间采集时建议持续观察。

5. 停止采集与下载

  1. 采集结束后点击 停止采集。
  2. 等待状态回到 idle，并显示最新 session 的文件大小。
  3. 点击 下载最新 Session。
  4. 手机端会从眼镜端下载 ZIP，保存到 App 私有 Downloads 目录下的 RokidOfflineSessions。
  5. 页面会显示完整文件路径和 ZIP 大小。需要发给 PC 时，可通过系统文件管理器、ADB 或分享方式导出。
手机端保存路径通常类似：/sdcard/Android/data/com.aiglasses.poc/files/Download/RokidOfflineSessions/session_xxx.zip。

6. Session ZIP 内容

文件说明
video.mp4眼镜端本地 H.264 MP4 录像。
imu.jsonlIMU/姿态传感器样本，每行一个 JSON 事件。
frames.csv逐帧编码时间戳、Camera sensor timestamp、flags、大小等。
events.jsonl采集开始、传感器注册、异常等事件日志。
session.json本次 session 元数据、分辨率、FPS、文件大小、错误状态等。

后处理时建议以 frames.csv 的视频帧时间戳和 imu.jsonl 的传感器时间戳做软件对齐。

7. 验收标准

  • 点击 采集状态 后能自动发现眼镜 IP，并显示 RokidBridge 1.6 / versionCode 7。
  • 点击 开始采集 后状态进入 recording。
  • 录制 5 秒以上，encoded_frame_count、imu_sample_count、video_bytes 持续增长。
  • 点击 停止采集 后生成最新 session。
  • 点击 下载最新 Session 后手机本地出现 session_xxx.zip。
  • 解压 ZIP 后，video.mp4 可播放，imu.jsonl 和 frames.csv 非空。

8. 常见问题排查

现象原因与处理
采集状态失败，提示未发现眼镜 HTTP 服务确认眼镜端 RokidBridge 已打开；确认手机和眼镜在同一 Wi-Fi/热点；必要时重开眼镜端 App 后再点 采集状态。
开始采集失败，出现 SecurityException眼镜端可能不是本次 release 的 RokidBridge。请更新到 1.6 / versionCode 7，该版本包含前台相机服务和高频传感器权限。
状态一直 starting等待 3–5 秒后再次点 采集状态；若仍无编码帧增长，停止后重启眼镜端 App。
下载失败确认已经停止采集并生成 session；确认手机和眼镜仍在同一网络；再次点击 下载最新 Session。
长时间录制发热缩短单段录制时长，录制间隔让设备降温；必要时降低目标 FPS/分辨率后再做长期采集版本。
手机 App 和眼镜端状态不一致先点 采集状态刷新，以眼镜端 HTTP 返回状态为准；如果 CXR 状态不同步，不影响本离线采集的 HTTP 控制链路。

9. ADB 辅助验证（可选）

如果测试人员具备 ADB/局域网调试条件，可直接访问眼镜 HTTP 服务验证。

  1. 查询状态：GET http://<眼镜IP>:18080/status
  2. 开始采集：POST http://<眼镜IP>:18080/sessions/start?width=1280&height=720&fps=60
  3. 停止采集：POST http://<眼镜IP>:18080/sessions/current/stop
  4. 查询列表：GET http://<眼镜IP>:18080/sessions
  5. 下载：GET http://<眼镜IP>:18080/sessions/<session_id>/download
