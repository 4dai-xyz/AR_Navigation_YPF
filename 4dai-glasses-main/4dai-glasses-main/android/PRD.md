# App 子项目 PRD

更新时间：2026-04-29

## 1. 文档目标

本文档定义 AI 智能眼镜项目中 App 子项目的目标、范围、功能要求和验收口径。本文档只覆盖手机端子项目，不重复展开云端算法实现和建图标注生产细节。

## 2. 子项目定位

App 子项目是首版 Demo 的主控制端，负责把以下链路串起来：

1. 骑手选择目标店铺
2. 室外导航到最接近目标店铺的入场口
3. 进入室内后切换定位链路
4. 采集眼镜或手机图像
5. 调用云端定位
6. 调用云端路径规划
7. 展示导航提示和异常提示

## 3. 目标用户

- 外卖员
- 以电动车骑行为主
- 进入固定商场或办公楼后步行到店铺门口

## 4. 使用场景

### 场景 1：室外到室内连续导航

用户在手机端选择目标店铺，系统先进行室外导航。接近入场口后，App 切换到室内链路，驱动图像采集、上传和定位，再根据当前位置请求室内路径规划。

### 场景 2：室内定位低置信度

当云端返回低置信度或未命中结果时，App 暂停强导航提示，并提示补充图像或切换到备用图像来源。

### 场景 3：演示联调

研发或测试人员在手机端手动输入云端地址、场馆和目标点，验证定位接口、路径规划接口与图像来源切换链路。

## 5. 范围

### 纳入范围

- 手机端导航会话管理
- 目标 POI 选择
- 室内外状态切换
- 图像来源抽象 `ImageProvider`
- 眼镜来源与手机摄像头兜底来源切换
- 云端健康检查、场馆元数据、定位、路径规划调用
- 定位结果、路径结果与调试日志展示

### 不纳入范围

- 眼镜端显示
- 眼镜端独立导航运行
- 自动导入外卖订单
- 大规模多场馆账号体系
- 完整商用 UI 设计与埋点平台

## 6. 功能要求

### 6.1 会话与目标输入

App 必须支持：

- 手动输入云端 `base_url`
- 手动输入 `venue_id`
- 手动输入候选 `floor_id`
- 手动输入目标 `poi_id`
- 发起一次完整的室内导航联调会话

### 6.2 图像来源管理

当前 Demo App 必须支持以下来源标识，并与云端 `capture_mode` 对齐：

- `glasses_thumbnail`
- `glasses_album_sync`
- `phone_camera_fallback`

`glasses_private_stream` 保留为厂商私有实时图传接入后的扩展来源，当前没有真实 SDK 前不作为默认演示入口。

App 必须具备：

- 当前图像来源选择
- 图像来源状态检查
- 图像来源失败后的降级切换能力

### 6.3 室外 / 室内 Demo 状态机

当前 Demo App 必须以显式状态机驱动室外壳子、入场切换和室内联调链路，覆盖以下状态：

- `OUTDOOR_IDLE`
- `OUTDOOR_READY`
- `OUTDOOR_ROUTE_READY`
- `OUTDOOR_NAVIGATING`
- `ENTRY_HANDOFF_PENDING`
- `INDOOR_READY`
- `INDOOR_CAPTURING`
- `INDOOR_LOCATING`
- `INDOOR_LOW_CONFIDENCE`
- `INDOOR_ROUTING`
- `INDOOR_ROUTE_READY`
- `ERROR`
- `ABORTED`

当前 Android Demo 已接入真实高德室外导航；自动入场口判断和自动室外切室内仍属于后续目标能力，现阶段仍使用手动入场切换逻辑。

### 6.4 云端联调能力

App 必须支持调用：

- `GET /api/v1/health`
- `GET /api/v1/venues/{venue_id}/meta`
- `POST /api/v1/localization/visual-locate`
- `POST /api/v1/navigation/indoor-route`

### 6.5 结果展示

App 必须在页面可见展示：

- 当前连接状态
- 当前导航状态
- 当前图像来源
- 最近一次定位结果
- 最近一次路径规划结果
- 最近日志

### 6.6 失败处理

App 在以下情况必须给出明确反馈：

- 云端不可达
- 定位超时
- 定位低置信度
- 路径规划失败
- 当前缺少可用定位结果而无法请求路径

## 7. 非功能要求

- 首版优先保证稳定联调，不追求复杂交互。
- 室内单次定位链路可接受 2 到 3 秒返回。
- App 不得把室内导航逻辑绑死在单一图像来源上。
- 定位失败时必须允许降级到手机侧来源。

## 8. 外部依赖

- 高德地图 SDK 或等效室外导航能力
- 眼镜厂商 Android SDK
- 云端定位与路径规划服务
- 场馆地图包与目标 POI 数据

## 9. 验收口径

满足以下条件可认为 App 子项目达到首版 Demo 可用状态：

1. 能配置云端地址并成功调用健康检查与场馆元数据接口。
2. 能选择任一图像来源并触发定位请求。
3. 能在获得定位结果后请求路径规划接口。
4. 能区分 `ok`、`low_confidence`、`not_found` 三类定位状态。
5. 能在图像来源或请求失败时给出可见提示。
6. 作为手机端演示壳子，可完成室内导航链路联调。
