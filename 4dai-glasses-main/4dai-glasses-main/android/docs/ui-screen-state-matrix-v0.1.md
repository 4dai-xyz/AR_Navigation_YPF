# Android App UI 页面与状态矩阵 v0.1

更新时间：2026-05-08

## 1. 目的

本文档把最终 UI 页面、主状态、按钮与现有代码口径对齐，方便开发者和开发者 AI 在实现时快速确认“哪个状态应该渲染成哪个页面”。

## 2. 页面清单

| 页面 ID | 页面名称 | 触发来源 | 主目标 | 权威视觉参考 |
| --- | --- | --- | --- | --- |
| `S01` | 搜索首页 | App 初始室外态 | 开始搜索 | `01`, `03` |
| `S02` | 搜索结果页 | 在 `S01` 输入关键词 | 快速选中候选结果 | `05` |
| `S03` | 目标确认页 | 在 `S02` 选择一个结果 | 明确入口与店铺关系 | `03` |
| `S04` | 室外路线已就绪页 | 入口路线准备完成 | 开始导航或打开高德 | `01` |
| `S05` | 接近入口 / 场馆交接页 | 接近入口或外部高德回流 | 进入场馆 | `01`, `03` |
| `S06` | 室内导航主界面 | 点击 `进入场馆` | 正常室内主流程 | `01`, `04`, `06` |
| `S07` | 低置信度辅助页 | 室内保留链路触发低置信度 | 补拍 / 稍后再试 | `04` |
| `S08` | 到达页 | 室内到达目标 | 完成 | `04` |
| `S09` | 隐藏 Debug Drawer | 长按顶部状态胶囊 | 进入内部工具层 | `06` |
| `S10` | 十字方向键与楼层控件面板 | 在 `S09` 选择手动演示 | 推进 `manual_demo` | `06` |

## 3. 搜索筛选器矩阵

| 筛选器 | 搜索对象 | 室外终点 | 是否默认进入室内链路 | 备注 |
| --- | --- | --- | --- | --- |
| `店铺` | 门店、商铺、品牌店 | 所属场馆最近入口 | 是 | 先入口，后店铺 |
| `商场入口` | 商场入口点 | 选中的入口点 | 否 | 除非后续再选店铺 |
| `写字楼` | 楼宇、大厦、园区入口 | 楼宇主入口 | 视场馆包而定 | 第一版先做入口到达 |
| `小区` | 小区门岗、大门、门点 | 选中的门点 | 否 | 第一版只做到入口 |

## 4. `NavState` 到页面映射

| `NavState` | 页面 ID | 顶部胶囊 | 底部主按钮 | 辅助动作 |
| --- | --- | --- | --- | --- |
| `OUTDOOR_IDLE` | `S01` | 搜索/室外待机 | 无固定主按钮，搜索优先 | 类型筛选、最近搜索 |
| `OUTDOOR_READY` | `S01` / `S04` | 室外就绪 | `开始导航` 或 `前往入口` | `高德导航` |
| `OUTDOOR_ROUTE_READY` | `S04` | 路线已就绪 | `开始导航` | `打开高德` |
| `OUTDOOR_NAVIGATING` | `S05` 或室外导航中间态 | 导航中 / 接近入口 | `进入场馆` 或 `继续导航` | `继续高德` / `全览` |
| `ENTRY_HANDOFF_PENDING` | `S05` | 等待进入场馆 | `进入场馆` | `继续高德` 或返回 |
| `INDOOR_READY` | `S06` | 室内待机 / 首条提示 | `继续` | `上一步`, `更多` |
| `INDOOR_CAPTURING` | `S06` 或 `S07` | 采图中 | `稍候` | `更多` |
| `INDOOR_LOCATING` | `S06` 或 `S07` | 定位中 | `稍候` | `更多` |
| `INDOOR_LOW_CONFIDENCE` | `S07` | 低置信度提醒 | `补拍一张` | `稍后再试` |
| `INDOOR_ROUTING` | `S06` | 正在请求路径 | `稍候` | `更多` |
| `INDOOR_ROUTE_READY` | `S06` 或 `S08` | 室内指令 / 到达 | `继续` 或 `完成` | `上一步`, `更多` |
| `ERROR` | 保留当前页并浮现错误态 | 错误摘要 | 与当前流程相关的恢复动作 | `查看调试` |
| `ABORTED` | 中止态页 | 演示已中止 | `返回室外` | `查看调试` |

## 5. 各页面主操作矩阵

| 页面 ID | 主按钮 | 次按钮 | 备注 |
| --- | --- | --- | --- |
| `S01` | 无固定主按钮 | 无 | 点搜索结果本身作为主动作 |
| `S02` | 无固定主按钮 | 无 | 点列表行进入确认页 |
| `S03` | `前往入口` | `高德导航` | 若是非店铺类型，可替换为 `开始导航` |
| `S04` | `开始导航` | `打开高德` | 外部高德会话存在时改为 `继续高德` |
| `S05` | `进入场馆` | `继续高德` | 接近入口后出现 |
| `S06` | `继续` | `上一步`, `更多` | `更多` 打开二级层 |
| `S07` | `补拍一张` | `稍后再试` | 当前仅为保留链路辅助态 |
| `S08` | `完成` | 无 | 可选增加 `退出室内` |
| `S09` | 无固定主按钮 | 内部工具入口列表 | 二级调试层 |
| `S10` | 无固定主按钮 | `重置`, `退出室内` | 方向与楼层按钮为主要交互 |

## 8. 与现有代码结构的映射建议

| 新 UI 概念 | 当前代码承载对象 | 说明 |
| --- | --- | --- |
| 顶部状态胶囊 | `TopCardUiModel` | 从大状态卡收口为紧凑胶囊 |
| 底部主 Dock | `BottomActionBarUiModel` | 保留状态驱动，但减少首层按钮数量 |
| 地图浮动按钮 | `MapChromeUiModel` | 保留现有回中、方向、全览能力 |
| 隐藏 Debug Drawer | `DebugPanelUiModel` | 改为隐藏触发与分层展示 |
| 室内到达态 | `ManualIndoorDemoState.arrived` | 到达时切换为 `S08` |
| 外部高德入口 | `AmapExternalNavigationLauncher` | 直接复用现有实现 |

## 9. 必须避免的错误映射

- 不要把 `INDOOR_READY` 默认渲染成首层十字方向键控制台。
- 不要把 `S02` 做成只能看见 2 到 3 条结果的小抽屉。
- 不要把 Debug 表单直接放在 `S06` 首屏。
- 不要把“店铺结果选中”直接等同于“室外终点是店铺门口”。
