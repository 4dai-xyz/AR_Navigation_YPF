## 9. 禁止出现的误导文案

- `自动进入室内`
- `实时室内定位稳定运行中`
- `眼镜导航已接入`
- `已自动识别入口`

## 10. 文案风格规则

- 每条文案尽量控制在 12 个汉字以内。
- 主按钮优先使用动词开头。
- 室外目标统一叫“入口”，室内目标统一叫“店铺门口”。
- 错误提示尽量给出下一步动作，不只说失败。
