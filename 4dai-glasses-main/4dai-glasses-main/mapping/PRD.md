# 建图标注子项目 PRD

更新时间：2026-04-28

## 1. 文档目标

本文档定义 AI 智能眼镜项目中建图标注子项目的目标、范围、数据交付和验收口径。本文档聚焦内部数据生产流程，不展开 App 和云端的实现细节。

## 2. 子项目定位

建图标注子项目是首版室内导航的地图与定位资产供应方，负责：

1. 基于 S20 形成场馆几何底图
2. 生成人工可维护的导航语义数据
3. 补采视觉定位所需 RGB 图像
4. 组装出云端和 App 可消费的场馆地图包

## 3. 服务对象

- 云端子项目
- App 子项目
- 算法评估与联调测试

## 4. 范围

### 纳入范围

- S20 现场采集
- 点云后处理
- 楼层切分与底图生成
- 入口、POI、扶梯和路网语义标注
- RGB 补采
- keyframe 与特征资产整理
- 地图包装配
- 校验与发布

### 不纳入范围

- 无预建图自由 SLAM
- 众包建图平台
- 自动语义标注平台
- 多城市大规模地图运营系统

## 5. 交付目标

首版建图标注子项目必须交付可用的场馆地图包，至少覆盖：

- 1 到 2 个固定商场或办公楼
- 明确入场口
- 明确目标店铺门口 POI
- 明确跨层扶梯连接
- 明确可规划路网
- 明确可用于重定位的 keyframe 与索引资产

## 6. 功能要求

### 6.1 几何底图生产

必须支持：

- 采集完整楼层点云
- 形成可用于标注的俯视底图
- 给出统一场馆局部坐标系

### 6.2 导航语义标注

必须支持维护以下对象：

- `entrances`
- `pois`
- `connectors`
- `route_graph.nodes`
- `route_graph.edges`

### 6.3 视觉定位资产准备

必须支持：

- 沿演示路线补采 RGB 图像
- 形成 `keyframes.jsonl`
- 形成 `cameras.json`
- 形成 `descriptors.faiss`
- 形成局部特征索引文件

### 6.4 地图包装配与发布

必须支持：

- 按统一字段规则组织地图包目录
- 通过校验脚本验证字段和引用关系
- 通过发布脚本生成 zip 与摘要产物

## 7. 非功能要求

- 首版优先保证数据可用、关系正确、包结构稳定。
- 坐标体系必须统一，避免 App、云端、标注三方各自维护副本。
- 发布前必须可复现校验结果。

## 8. 外部依赖

- S20 采集设备
- 现场采集权限
- 点云处理工具
- 标注工具
- RGB 补采设备
- 特征与检索生成工具链

## 9. 验收口径

满足以下条件可认为建图标注子项目达到首版 Demo 可用状态：

1. 目标场馆可以产出完整地图包目录。
2. 地图包通过 `validate_venue_package.py` 校验。
3. 地图包可以通过 `publish_venue_package.py` 打包发布。
4. 云端能基于该地图包加载 POI、楼层、路网和定位资产。
5. 演示路线涉及的入口、扶梯、目标店铺门口均已标注齐全。
